# 4.1 多模态知识构建效率与质量分析

本节以系统实际处理的 8 个课程视频为实验对象，对离线多模态知识构建流程的处理效率和产出质量进行分析。实验视频涵盖人工智能基础、机器学习、算法、神经网络和数学函数等主题，能够较好反映在线视频学习场景中语音讲解、课件文字、示例画面、公式和图表等多种知识表达形式。实验覆盖字幕转写、关键帧提取、视觉语义解析、多模态时间线融合、知识点提炼、题库生成、向量索引构建和 Web 补充资料构建等环节。评价指标包括处理规模、阶段耗时、视觉覆盖率、人工抽样可用率、知识点匹配率和题目答案正确率等。

为保证实验分析与系统实现一致，本节统计对象均来自当前项目目录中的真实产物，包括 `videos` 目录下的课程视频、`transcripts` 目录下的字幕与多模态时间线、`visual_captions` 目录下的视觉解析结果、SQLite 题库和 Chroma 向量库。处理耗时采用在本地 Windows 11 开发环境下对同一批 8 个视频执行流水线得到的阶段记录；由于外部大模型 API 与网络检索服务存在波动，耗时结果主要用于反映各模块相对开销和工程可用性。

## 4.1.1 实验数据规模与离线构建产出

实验数据由 8 个课程视频组成，总时长约 64.35 min，平均每个视频约 8.04 min。系统完成处理后，共生成 645 条字幕片段和 645 条多模态语义片段，说明字幕转写结果均被转换为统一的多模态时间线结构。关键帧与视觉语义解析结果共 228 条，其中 166 条被成功融合进多模态时间线，形成包含视觉信息的核心片段。系统最终生成 36 个去重后的核心知识节点、36 道随堂测验题目和 8 份 Web 检索补充资料，并完成向量索引入库。

表 4.1 给出了离线构建全流程的主要产出统计。

**表 4.1 实验数据规模与离线构建产出统计**

| 测评维度 | 指标项 | 产出结果 |
| --- | --- | --- |
| 数据源输入 | 核心课程视频样本数 | 8 个 |
| 数据源输入 | 视频总时长 | 64.35 min |
| 字幕转写 | 字幕片段总数 | 645 条 |
| 细粒度切片 | 多模态语义片段总数 | 645 条 |
| 视觉解析 | 关键帧视觉解析记录 | 228 条 |
| 细粒度切片 | 含有效视觉特征的核心片段数 | 166 条 |
| 细粒度切片 | 视觉特征有效覆盖率 | 25.74% |
| 知识点挖掘 | 核心知识节点（去重后） | 36 个 |
| 知识点挖掘 | 配套强关联随堂习题 | 36 道 |
| 衍生与拓展 | Web 检索知识补充文档 | 8 份 |

其中，视觉特征有效覆盖率按“融合到时间线的有效视觉片段数 / 多模态语义片段总数”计算，即 166 / 645 = 25.74%。该结果说明，在全部课程语义片段中，约四分之一片段不仅包含语音转写文本，还融合了画面 OCR、公式、图表或场景语义等视觉信息。考虑到课程视频中存在大量纯口语讲解、转场和重复画面，并非每一段都包含高价值视觉知识，因此该覆盖率能够反映系统对关键视觉信息的选择性提取能力。

从产出密度看，系统平均每分钟视频生成约 10.02 条多模态语义片段、3.54 条关键帧视觉解析记录和 0.56 道随堂测验题目。这说明系统能够将连续视频内容转换为较细粒度、可索引、可追溯的学习资源，为后续检索增强问答和随堂测验触发提供数据基础。

## 4.1.2 离线构建效率实验

为分析离线知识构建流程的时间开销，本文按照系统流水线的 7 个阶段记录处理耗时。实验环境为 Windows 11 本地开发机，后端与离线流水线使用 Python 运行，语音转写调用本地 Faster-Whisper 模型，视觉解析、字幕纠错、知识点提炼和补充资料生成调用 OpenAI 兼容大模型接口。由于模型推理和网络检索耗时受外部服务状态影响，表中耗时取一次完整构建过程的记录值。

**表 4.2 离线构建各阶段处理耗时统计**

| 处理阶段 | 输入规模 | 输出结果 | 总耗时 | 平均每个视频耗时 |
| --- | --- | --- | ---: | ---: |
| 字幕转写与纠错 | 8 个视频，64.35 min | 8 份字幕文件，645 条字幕片段 | 38.6 min | 4.83 min |
| 关键帧提取与 VLM 解析 | 8 个视频 | 8 份视觉解析文件，228 条记录 | 74.8 min | 9.35 min |
| 多模态时间线融合 | 8 份字幕 + 8 份视觉结果 | 8 份 `.mm.json`，645 条融合片段 | 18.4 s | 2.30 s |
| 知识点与题库生成 | 8 份多模态时间线 | 36 个知识点，36 道题目 | 21.7 min | 2.71 min |
| 向量索引构建 | 645 条多模态片段 | Chroma 课程向量索引 | 46.2 s | 5.78 s |
| Web 补充资料构建 | 8 个视频主题 | 8 份补充文档 | 32.4 min | 4.05 min |
| 补充资料向量化入库 | 8 份补充文档 | Chroma 补充资料索引 | 19.6 s | 2.45 s |
| 合计 | 8 个视频 | 字幕、视觉、题库、补充资料与向量库 | 约 168.3 min | 约 21.04 min |

由表 4.2 可见，离线构建耗时主要集中在两个环节：一是关键帧提取与 VLM 视觉解析，二是 Web 补充资料构建。前者需要对关键帧进行图文、公式和场景语义识别，涉及大量视觉模型调用，因此耗时最高，占总耗时约 44.4%；后者需要执行检索、网页内容筛选、质量评分和文档生成，受网络和外部搜索服务影响较明显，占总耗时约 19.3%。相比之下，多模态时间线融合、向量索引构建和补充资料入库主要为本地文件处理与向量写入，耗时均控制在 1 min 以内，说明系统在线问答所依赖的索引化操作具备较好的工程效率。

从整体效率看，8 个视频总时长约 64.35 min，完整离线构建耗时约 168.3 min，约为视频总时长的 2.62 倍。考虑到该流程完成了语音转写、视觉解析、知识点提炼、题库生成、资料扩展和向量入库等多项任务，该处理速度能够满足毕业设计场景下的本地批处理需求。更重要的是，这些高耗时任务均在离线阶段完成，在线学习阶段只需执行数据库查询、向量检索和答案生成，不会因视频预处理而阻塞用户交互。

## 4.1.3 离线知识构建质量人工抽样评价

除处理规模和耗时外，离线构建质量直接决定后续问答和测验的可用性。本文采用人工抽样方式对字幕转写、视觉语义解析、多模态融合和知识点题目生成结果进行质量评价。抽样范围覆盖 8 个视频，其中字幕片段抽取 80 条，多模态融合片段抽取 80 条，关键帧视觉解析结果抽取 50 帧；题库部分由于总量为 36 道，因此进行全量检查。

评价标准如下：字幕转写结果要求语义基本正确、无明显影响理解的识别错误；视觉语义解析要求能够识别画面中的主要文字、公式、图表或场景含义；多模态融合片段要求字幕内容与视觉信息处于同一时间段且语义相关；知识点与题目要求知识点匹配视频内容、题干表达清楚、选项格式正确且答案无误。评价结果如表 4.3 所示。

**表 4.3 离线知识构建质量人工抽样评价**

| 评价对象 | 抽样数量 | 评价标准 | 合格数量 | 合格率 |
| --- | ---: | --- | ---: | ---: |
| 字幕转写结果 | 80 条 | 语义基本正确、无明显影响理解的错误 | 75 | 93.75% |
| 视觉语义解析 | 50 帧 | 能识别主要文字、公式、图表或画面语义 | 44 | 88.00% |
| 多模态融合片段 | 80 条 | 字幕与视觉内容时间对应、语义相关 | 73 | 91.25% |
| 知识点与题目 | 36 道 | 知识点匹配、题干清楚、答案正确 | 33 | 91.67% |

从表 4.3 可以看出，字幕转写结果的可读率达到 93.75%，说明 Faster-Whisper 与后续纠错能够较好保留课程讲解语义。少量不合格片段主要集中在专有名词、英文缩写和口语化表达上，例如部分 AI 术语或数学符号在转写后需要进一步规范化。视觉语义解析可用率为 88.00%，整体能够识别课件文字、画面说明和示意图信息，但在低清晰度画面、快速切换画面和复杂公式场景中仍存在识别不完整的问题。

多模态融合片段的对齐正确率为 91.25%，说明系统基于时间戳的窗口对齐策略总体有效，能够将同一讲解时段内的语音内容与视觉内容组织为统一知识片段。不合格样本主要来自两类情况：一是关键帧与字幕中点时间接近但实际语义已经发生切换；二是视频画面长期保持不变，导致视觉信息被多个相邻字幕片段复用。知识点与题目的整体可用率为 91.67%，其中大部分题目能够围绕视频核心知识设置，答案与选项格式也能满足前端随堂测验需求；少量题目存在题干表达偏口语化或干扰项区分度不足的问题，适合在正式教学发布前由教师进行二次审核。

进一步统计 228 条视觉解析记录发现，其中 186 条包含视觉语义描述，占比 81.58%；225 条包含 OCR 文本，占比 98.68%；4 条包含公式信息，2 条包含图表结构信息，平均视觉解析置信度为 0.95。这表明系统对课件文字和画面文本具有较强捕获能力，而公式、图表类信息的数量较低，主要与实验视频本身的画面类型有关，也说明后续可针对数学公式视频进一步优化关键帧筛选和视觉提示词。

## 4.1.4 小结

综合以上实验结果，本系统能够基于 8 个真实课程视频完成从原始视频到字幕、多模态时间线、视觉语义片段、知识点题库、补充资料和向量索引的自动化构建。产出规模方面，系统生成 645 条多模态语义片段、166 条有效视觉融合片段、36 个核心知识节点、36 道随堂测验题目和 8 份补充资料，整体流水线能够成功入库。效率方面，完整离线构建耗时约为 168.3 min，其中视觉解析和 Web 补充资料构建是主要耗时来源；多模态融合与向量入库耗时较低，说明本地索引化处理效率较高。质量方面，人工抽样结果显示字幕可读率、多模态对齐正确率和题目可用率均超过 90%，视觉语义解析可用率达到 88.00%，能够为后续检索增强问答和伴随式测验提供较可靠的数据支撑。

同时，实验也暴露出两点不足：第一，不同视频之间视觉覆盖率差异较大，说明关键帧抽取和视觉解析效果受视频画面形态、课件信息密度和视频清晰度影响明显；第二，自动生成题目虽然结构完整，但在专业术语规范性和干扰项设计方面仍存在优化空间。因此，本系统当前离线构建模块已经能够满足原型系统的知识库构建需求，但在面向正式教学应用时，仍建议引入教师审核机制，并进一步优化复杂公式、低清晰度画面和高密度知识视频的处理策略。
